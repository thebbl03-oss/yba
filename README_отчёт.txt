2.1. ЧТО СДЕЛАНО В ЭТОЙ ИТЕРАЦИИ (полная статическая деобфускация)
-------------------------------------------------------------------
а) ПЕРЕСТАНОВКА ИМЁН РАССКРЫТА. Вход l(...) переименовывает поля таблицы
   по формуле  a[имя[(C1*b+C2) % N + 1]] = a[b+1]:
        ServHopper : C1=104729, C2=45175, N=80
        MethionV2  : C1=100193, C2=4417,  N=136
   Все 80/136 имён сопоставлены своим элементам (см. *_elements.lua).

б) ЧИСЛОВАЯ ОБФУСКАЦИЯ СНЯТА НА 100%:
        ServHopper : 1008 сайтов  a.Ba[K] or a:Ca/Da/Ea/Fa/Ga(...)
        MethionV2  : 1177 сайтов  g.lb/rb/Bb/wb[K] or g:ob/nb/ub/...(19 методов!)
   Каждое выражение ВЫЧИСЛЕНО вызовом настоящей функции-дешифрофатора
   (захваченной живьём из работающего объекта VM) и заменено значением.

в) СТРОКИ 2-ГО СЛОЯ РАСШИФРОВАНЫ: вызовы вида a:Ca(q"cOZK", q"Nd")
   (XOR-декодер m) расшифрованы и вставлены литералами: "pack", "unpack",
   "bit32", "byte", "char", "gmatch", ">i2", "<I4I4I4",
   "<I4I4I4I4I4I4I4I4I4I4I4I4I4I4I4I4" (формат инструкций 16x uint32)...

г) VM-БАЙТКОД ИЗВЛЕЧЁН: блоб в элементе a.k декодирован цепочкой
   q (base-N по 85-символьному алфавиту) → t (XOR/побайтово):
        vm_chunks/ServHopper_vm_bytecode.bin  — 1778 байт
        vm_chunks/MethionV2_vm_bytecode.bin   — 21 975 байт

д) ДИНАМИЧЕСКИЙ АНАЛИЗ В ПЕСОЧНИЦЕ (эмуляция Luau на Lua 5.1):
   потребовалось ДОБАВИТЬ отсутствующие в Lua 5.1 API:
        string.unpack/pack/packsize (форматы >I2, B, b, cNN, <I4...),
        table.pack, table.move, bit32.btest, bit32.countlz/countrz.
   После этого VM РАБОТАЕТ в песочнице:
     * ServHopper: парсит байткод (1246 чтений string.unpack),
       исполняет инструкции; доходит до строк 3-го слоя;
     * MethionV2 : ВЫПОЛНИЛСЯ ПОЛНОСТЬЮ БЕЗ ОШИБОК (16538 чтений)!

е) ПОВЕДЕНИЕ MethionV2 (зафиксировано исполнением):

2.2. АРХИТЕКТУРА VM (восстановлена)
-------------------------------------------------------------------
   :l(strtable, key)           — вход: перестановка имён, запуск a.Ha/a.Jb
   a.Ha / a.Jb                 — a:y() a:m() a:v() a:t() a:q() a:o()
                                 (строители XOR/base-N декодеров),
                                 a.E = a:E() (сборка VM), a:k() (запуск)
   a.k                         — a.E(a.t(a.q"БЛОБ"), b): декодирование
                                 байткода и запуск исполнителя
   a.E (результат)             — парсер: 2 стадии (a.T → a.la),
                                 строит фрейм VM (a.za — главный цикл)
   Инструкции: формат "<I4 x16" (16 uint32 на инструкцию) + побайтовое
   декодирование; константы — length-prefixed строки, шифруются
   МНОГОХОДОВЫМ XOR в рантайме (4-байтовые блоки, битовые операции).

Как читать *.deobf.lua (пресет IronBrew):
  return ( { l = function(a,q,n,...) ... end,  -- вход (перестановка имён)
             function(a) return function(c,q,r,l,b,h,f) ... end end,  -- фабрика
             ...
           } ) : l ( { "pa","xa",... } , "Ha" , ... )
  Элементы = фабрики обработчиков/декодеров; имена в {...} = методы a.
  Числа уже расшифрованы; строки 2-го слоя — литералы; диспетчеры
  while/repeat с числовыми состояниями теперь читаются напрямую.

2.4. ОГРАНИЧЕНИЯ (честно)
-------------------------------------------------------------------
  * Полный devirtualization (кастомный байткод → исходный Lua) —
    исследовательская задача; формат инструкций разобран до уровня
    «16x uint32 + побайтовое декодирование», семантика опкодов
    восстанавливается по фабрикам-обработчикам (элементы 1..80/138).
  * Строки 3-го слоя (в байткоде) шифруются МНОГОХОДОВЫМ XOR в
    рантайме; MethionV2 исполнился полностью (поведение задокументировано),
    но полная таблица расшифрованных строк 3-го слоя не снята —
    дамп промежуточных раундов XOR есть в traces/.

3.1. КАК РАБОТАЕТ АНТИ-ПЕСОЧНИЦА MOONSEC V3 (вскрыто динамически)

             ЛЕЧЕНИЕ: окружение executor-типа (syn/task/game/Drawing/
             utf8/... как цепочечные прокси; task.spawn реально исполняет
             переданную функцию).
  Барьер 4. Ложные номера строк в сообщениях об ошибках («Ybaa:7743»)
             — генерируются через math.random + gsub(":(%d*):") — просто
